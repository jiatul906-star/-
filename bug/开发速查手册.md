## 三、核心类型（src/common/types.ts）

```typescript
// ⭐ 角色配置 — 最重要的类型
interface CharacterConfig {
  id: string
  name: string
  gradient: string              // CSS gradient 色值
  imageDataUrl: string | null   // null = 用 CSS 默认脸
  personality: string           // ⭐ 性格描述（AI System Prompt 核心）
  voiceId: string
  speechStyle: string           // ⭐ 说话风格（注入 System Prompt）
  apiProfileId?: string         // ⭐ 角色专属 API（可选，不设则跟随全局）
}

// API Profile（ccswitch 风格多配置）
interface ApiProfile {
  id: string
  name: string
  baseUrl: string               // API endpoint，尾部不带 /
  apiKey: string
  model: string
  isActive: boolean
  maxTokens?: number
  temperature?: number
  createdAt: number
  updatedAt: number
}

// 智能体记忆
interface MemoryEntry {
  id: string
  content: string
  source: 'ai-extracted' | 'user-explicit'
  createdAt: number
  updatedAt: number
}

// 桌宠动作
interface PetAction {
  id: string
  label: string
  emoji: string
  videoPath: string
  order: number
  type: 'normal' | 'chat' | 'settings'
}

// 聊天消息
interface ChatMessage {
  id: string
  role: 'user' | 'assistant' | 'system'
  content: string
  timestamp: number
  characterId: string
}
```

## 五、AI 调用流程（核心）

### 5.1 buildSystemPrompt（构造 System Prompt）

```typescript
// 文件: src/renderer/plugins/chat/api.ts
export function buildSystemPrompt(char: CharacterConfig, memory: MemoryEntry[]): string
```

输出格式：
```
你是{char.name}。

你的性格：{char.personality}

你的说话风格：{char.speechStyle}

关于与你对话的人，你记得：
- {memory[0].content}
- {memory[1].content}

请用自然、拟人化的方式回复。保持与你的角色性格一致。回复简洁，不要过长。
```

### 5.2 streamChat（流式 API 调用）

```typescript
// 文件: src/renderer/plugins/chat/api.ts
export async function* streamChat(
  messages: ChatMessage[],
  profile: ApiProfile,
  systemPrompt: string,
  signal?: AbortSignal,
): AsyncGenerator<string>
```

- 调用 `{profile.baseUrl}/chat/completions`（OpenAI 兼容接口）
- SSE 流式解析 `data: {choices[0].delta.content}`
- 已测试可用：DeepSeek (`https://api.deepseek.com/v1`, `deepseek-chat`)

## 六、状态管理模式

### 6.1 Zustand Store（pet-store.ts）

```typescript
const usePetStore = create<PetState>((set, get) => ({ ... }))

// 常用操作：
usePetStore.getState()                        // 直接读
usePetStore.setState({ key: value })          // 直接写（无需 selector）
const { characters, updateCharacter } = usePetStore()  // hook 方式
```

### 6.2 角色更新标准模式

**⚠️ 任何角色字段修改必须遵循三步**：

```typescript
// 1. 更新内存 Zustand store
const updated = { ...activeChar, fieldName: newValue }
updateCharacter(updated)

// 2. 构造新的全量角色列表
const all = characters.map((c) => (c.id === activeChar.id ? updated : c))

// 3. 持久化到磁盘（通过 IPC → 主进程广播到所有窗口）
persist(all, activeCharacterId)
```

const settingPatterns = [

  && extractedTrait.length >= 1
  && extractedTrait.length <= 30
  && !questionWords.test(extractedTrait)

## 九、常见 Bug & 避坑

| # | 问题 | 原因 | 修复 |
|---|------|------|------|
| 1 | 修改源码后不生效 | 构建产物未更新 | `npx electron-vite build` 重新构建 |
| 2 | 设置页输入无效 | 未绑定 value/onChange | 必须绑定状态 → `updateCharacter` → `persist` 三步 |
| 3 | JSX 中文引号报错 | `"` 和 `"` 被当成属性分隔符 | 改用 `{'...'} ` 包裹含中文引号的字符串 |
| 4 | framer-motion exit 动画慢 | 共享 `transition` prop，exit 也走 spring | 用 **variants** 给 exit 单独设 `{ duration: 0.1 }` |
| 5 | 关闭菜单后旧消息残留 | `setChatMessages` 未清空 | `handleCloseMenu` 中 `setChatMessages([])` |
| 6 | 聊天中 "你是谁" 被当成设定 | `/^你是(.+)$/` 太宽泛 | 添加疑问词黑名单 |
| 7 | `buildSystemPrompt` 导入路径 | 跨目录引用 | `import { buildSystemPrompt } from '../plugins/chat/api'` |
