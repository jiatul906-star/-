## 关键架构变化（2026-07-08）

### 数据存储：从平铺 JSON → 按角色文件夹

```
%APPDATA%/with-u/character/
├── _index.json              ← {activeId, entries: {[id]: {id, folderName}}}
├── 小桃/
│   ├── config.json          ← 单角色配置（无 base64 图片）
│   ├── portrait.png         ← 立绘
│   ├── avatar.png           ← 头像
│   ├── chat-history.json    ← 聊天记录
│   ├── agent-memory.json    ← 人设/记忆
│   └── video/               ← 动作视频 + 空闲播放视频
└── 小蓝/（同上）
```

### 类型变化

- `CharacterConfig` **已移除** `imageDataUrl` / `avatarDataUrl`
- 运行时图片：`characterPortraits[charId]` / `characterAvatars[charId]`（Zustand 缓存）
- `PetAction.videoPath` 现在是纯文件名，不是绝对路径

### 新增 IPC

| 通道 | 入参 | 返回 |
|------|------|------|
| `dialog:openImage` | `charName, imageType` | dataUrl \| null |
| `pet-image:getCurrent` | `charName, imageType` | dataUrl \| null |
| `dialog:openVideo` | `charName` | 文件名 \| null |
| `character:getVideoPath` | `charName, fileName` | 完整路径 \| null |
| `character:listVideos` | `charName` | `string[]`（文件名） |
| `dialog:openCharacterVideoFolder` | `charName` | void |

### 空闲视频播放

- PetWindow 空闲时自动随机播放 `character/{name}/video/` 中的 mp4
- 间隔：首次 3s，循环 5-10s 随机
- 防护：菜单打开/拖拽/动作视频播放/聊天中 → 不触发

## 四、常见 Bug & 避坑

| # | 问题 | 原因 | 修复 |
|---|------|------|------|
| 1 | 修改源码不生效 | 未 build | 重新 `electron-vite build` |
| 2 | 设置页输入无效 | 未绑定 value/onChange | 状态绑定 → `updateCharacter` → persist 三步 |
| 3 | JSX 中文引号报错 | 被当成属性分隔符 | `{'...'} ` 包裹 |
| 4 | framer-motion exit 慢 | 共享 transition | variants 给 exit 设 `{duration:0.1}` |
| 5 | 关闭菜单后消息残留 | `setChatMessages` 未清空 | `setChatMessages([])` |
| 6 | "你是谁"被当成设定 | `/^你是(.+)$/` 太宽泛 | 疑问词黑名单过滤 |
| 7 | 图片/视频不显示 | charName 给错了 | openImageDialog 现在要传 `charName` 不是 `charId` |
