# 功能清单

> 状态：起草中 | 最后更新：2026-05-14

## 原则

- **不做 MVP 删减**：所有功能都是必做项
- **UI 可迭代**：界面设计允许多轮打磨，不做一次性交付
- **DIY 高自由度**：用户能自定义的都让它可自定义

## 功能列表

### 1. AI 聊天

| 子功能 | 说明 |
|--------|------|
| 拟人化对话 | AI 按角色性格回复，非通用问答 |
| 上下文记忆 | 角色记住和用户聊过什么 |
| 情感表达 | 回复带有情绪色彩，角色有"心情" |
| 流式输出 | 逐字显示，不是一次性弹出 |

### 2. DIY 角色创建

| 子功能 | 说明 |
|--------|------|
| 外观定制 | 上传角色图片（立绘/头像） |
| 性格设定 | 用自然语言描述性格，AI 自动理解 |
| 声音选择 | 多种音色可选，绑定到角色 |
| 说话风格 | 口头禅、语气、回复长度偏好 |
| 外观细节 | 裁剪、缩放、多图切换 |

### 3. TTS 语音

| 子功能 | 说明 |
|--------|------|
| 文字转语音 | AI 回复自动念出来 |
| 角色绑定音色 | 不同角色用不同声音 |
| 流式播放 | 边生成边播放，减少等待 |

### 4. 桌宠

| 子功能 | 说明 |
|--------|------|
| 桌面悬浮 | 角色在桌面上独立窗口显示 |
| 闲置动画 | 待机时有呼吸、眨眼等动画 |
| 交互反馈 | 点击有反应，说话时嘴型同步 |
| 多状态 | 开心/难过/生气/惊讶等表情 |

### 5. 其他

| 子功能 | 说明 |
|--------|------|
| 多角色管理 | 创建、切换、删除多个 AI 伴侣 |
| UI 主题 | 主题色、聊天背景可自定义 |
