# UI 规格

> 状态：已确定 | 最后更新：2026-05-16

## 核心理念

角色和窗口**分离但关联**——关闭窗口角色不消失，退回桌面。角色始终在线，是一个"伴侣"而非软件装饰。

---

## 整体风格

- 浅色为主，窗口圆润，参考 QQ 面板布局
- 字体：微软雅黑（`"Microsoft YaHei", "Segoe UI", system-ui, sans-serif`）
- 面板风格参考 QQ（左侧竖排头像栏 + 右侧内容区）

---

## 三级菜单结构

### Level 1 — 桌宠模式（桌面流浪）

> 已确定。

- 角色独立悬浮桌面，无窗口
- 角色自由走动/待机，可拖拽到任意位置
- **戳角色**：点击角色身体 → 随机反应动画 + 一句台词（与摸头不同，更随机）
- **右键**：弹出环形菜单（聊天/摸头 + 扩展条目）+ 迷你聊天气泡
  - 漫画风，从角色嘴边引出，无历史记录
  - **停留**：鼠标移出气泡区域后消失
  - **连续右键**：堆叠，已有气泡向上飘动，新气泡在下方出现
  - **朝向**：根据角色在屏幕上的位置动态调整
- **左键拖拽**：角色可被拖拽到桌面任意位置，播放"被抓起来"的动作帧，放下切回站立/坐下

### Level 2 — 聊天模式

参考 QQ 面板：左侧竖排头像栏 + 右侧聊天区。

```
    ┌────────────────────────────┐
    │     角色骑在顶栏边框       │
    ├────┬───────────────────────┤
    │ ○  │  角色A                │  ← 顶栏：小头像 + 名字
    │ ○  ├───────────────────────┤
    │ ○  │                      │
    │ ○  │  聊天消息区           │
    │ ○  │  AI气泡 / 用户气泡     │
    │ ○  │                      │
    │ ○  │                      │
    │ +  ├───────────────────────┤
    │    │  输入框         [发送] │
    └────┴───────────────────────┘
       ↑
      左侧角色列表（竖排圆形头像）
      选中态高亮
```

- **左侧角色栏**：竖排圆形头像列表，可切换角色
  - 多角色时：52px 宽，完整显示头像列表
  - 单角色时：自动缩小到 22px，迷你头像+"+"号
  - 通过顶栏下拉入口也可切换，侧栏不是唯一入口
- 窗口圆润，偏窄，适合常驻桌面
- 移动窗口 → 角色跟着走
- 拖拽角色离开窗口 → 回到 Level 1
- 把角色扔到窗口顶部 → 自动坐回去
- 流式逐字输出，末尾有呼吸光标
- **可拖拽窗口边缘调大小**，设置最小尺寸防止布局崩坏

**窗口尺寸**：

| 属性 | 值 |
|------|-----|
| 默认宽 | 960px |
| 默认高 | 680px |
| 最小宽 | 680px |
| 最小高 | 480px |

**显示密度**：用户可选择两种模式

| 模式 | 正文 | 行高 | 气泡间距 |
|------|------|------|---------|
| 舒适 | 15px | 1.6 | 12px |
| 紧凑 | 14px | 1.5 | 8px |

### Level 3 — 设置模式

> 已确定。

- 设置是独立弹窗，浮在聊天窗口上方
- 关闭弹窗 → 回到聊天，内容不丢失
- 角色骑在设置弹窗的标题栏上
- 弹窗布局：左侧分类导航 + 右侧内容区

```
         ┌──── 设置弹窗 ──────────┐
         │  设置    🐱       [✕]  │
         ├────────┬───────────────┤
         │        │               │
         │  角色   │   当前角色编辑 │
         │  ○ 小桃 │               │
         │  ○ 小黑 │   [内容区]    │
         │  + 新建 │               │
         │        │               │
         │ ────── │               │
         │  AI设置 │               │
         │  外观   │               │
         └────────┴───────────────┘
```

#### 左侧分类详细内容

**1. 角色编辑**

标签式自由切换，新建和编辑均为同一界面：

```
┌─────────────────────────────────┐
│ [外观]  [性格]  [声音]           │
├─────────────────────────────────┤
│    当前标签内容（见下方）          │
└─────────────────────────────────┘
```

**① 外观**
| 操作 | 说明 |
|------|------|
| 立绘 | 上传角色立绘图（对话时展示） |
| 头像 | 上传圆形头像（侧栏/托盘图标用） |
| 桌宠形象 | 上传桌面流浪时的角色图 |
| 裁剪 | 每张图支持简单裁剪 |
| 实时预览 | 上传后立即显示缩略图 |

**② 性格**
- **模板模式**：QQ 标签式预设标签，点击添加/删除（"温柔""傲娇""话唠""安静""幽默""毒舌""元气""冷淡"等）
- **自由文本模式**：文本区，直接自然语言描述
- 两种模式可叠加——标签快捷 + 文本补充细节

**③ 声音**
- 自由调节滑块：语速、音调、音量
- 试听按钮：播放示例语音

点"+"新建 → 清空表单，三标签自由填写，完成后出现在左侧列表。

---

**2. AI 设置**

| 字段 | 说明 |
|------|------|
| API 地址 | 文本输入框，填 API endpoint URL |
| API Key | 密码输入框 |
| 测试连接 | 按钮，发送测试请求验证配置是否可用 |

- 默认支持 OpenAI 兼容接口，可接免费/付费模型
- 不预设模型名称（由用户端 API 地址决定）

---

**3. 界面外观**

同设计系统的设定，提供可视化切换：

- **主题色**：暖桃 / 薄荷 / 薰衣草 / 奶咖 / 樱花（点击色块预览切换）
- **明暗模式**：浅色 / 暗色（开关切换）
- **显示密度**：舒适 / 紧凑（单选）

## 窗口与角色关联规则

| 状态 | 窗口 | 角色位置 |
|------|------|---------|
| Level 1 | 无窗口 | 桌面任意位置，可拖拽 |
| Level 2 | 聊天窗口 | 骑在窗口顶栏边框 |
| Level 3 | 聊天窗口 + 设置弹窗 | 骑在设置弹窗标题栏 |
| 关闭设置弹窗 | 回到 Level 2 | 坐回聊天窗口顶栏 |
| 切换角色（侧栏/托盘） | 不变 | 桌宠形象跟变为新角色 |

### 保留想法

- **多桌宠同屏**：多个角色同时在桌面，可互动/掐架。技术复杂度高，暂保留。

---

## 对话气泡设计（Level 1 右键）

- 漫画风格，从角色嘴边引出
- 无历史记录功能
- 短暂显示后自动消失
- 不是矩形输入框，是纯展示气泡

---

## 设计原则

1. **递进式复杂度**：Level 1 最简，Level 3 功能最全
2. **角色不挡内容**：角色坐在边框上，不占窗口内部空间
3. **始终陪伴**：关闭窗口不等于关闭角色
4. **窗口小巧**：不做大而全的面板，适合长期驻留桌面

## UI 设计难点与细节处理

### 1. Level 2 → 3 过渡方式

> 已确定：独立弹窗，浮在聊天上方。

设置作为弹窗浮在聊天窗口上面，而非独立窗口或替换内容区。聊天窗口保持原样，设置遮住一部分内容。关闭设置弹窗 → 直接回到聊天，内容不丢失，角色坐回聊天窗口顶栏。

---

### 2. 单角色时左侧栏闲置

Level 2 左侧竖排头像栏参考 QQ，但 QQ 有几十个好友，而本产品大部分用户可能只创建 1 个角色。此时左侧栏只有一个头像 + 一个"+"号，占用宽度但无信息量。

**需要决策**：左侧栏是否在单角色时自动隐藏？还是始终显示但缩小宽度？

---

### 3. TTS 播放缺视觉反馈

TTS 是差异化功能，但当前设计没有定义语音播放时的 UI 状态：

- 角色嘴型同步怎么做？（素材是否支持？）
- AI 气泡正在播放语音时，有没有声波/音轨指示？
- 播放中用户又发了一条消息，是打断还是排队？
- 流式播放加载失败时的反馈？

**需要决策**：TTS 播放态至少需要气泡上的声波指示器 + 角色一个"说话中"状态。

---

### 4. 空状态——初始启动无角色

> 已确定。

用户首次打开软件时，进入角色选择界面：

- **桌宠**：暂不显示（选择前无角色）
- **窗口**：展示 4 个官方预制角色的横排卡片（立绘 + 名字 + 性格标签预览）
- **选择角色**：点击某个角色 → 确认 → 角色正式激活
- **激活后**：桌宠窗口出现，角色跳入引导模式

**引导模式**（选中角色后自动进入）：
- 桌宠出现在桌面，右键气泡依次弹出引导语（"嘿，我是 XX！""在这里聊天""去设置里改我的外观哦"等，3-5 句）
- 聊天窗口自动打开，角色坐顶栏
- 引导结束后角色保持正常状态，用户可自由使用

```
   首次启动窗口

  ┌─────────────────────────────────┐
  │       选择你的第一位伙伴          │
  ├──────┬──────┬──────┬─────────────┤
  │      │      │      │             │
  │ 小桃 │ 小黑 │ 小雪 │   小灰      │
  │ 元气 │ 傲娇 │ 温柔 │   冷淡      │
  │      │      │      │             │
  │[选择]│[选择]│[选择]│  [选择]      │
  ├──────┴──────┴──────┴─────────────┤
  │          [确认]                  │
  └─────────────────────────────────┘
```

### 5. 加载与错误状态

> 已确定。原则：角色优先用自身状态反馈，关键错误弹出操作入口。

| 场景 | 反馈方式 |
|------|---------|
| **AI 请求发送中** | 角色思考表情（歪头/眨眼），气泡内三个跳动点 |
| **AI 请求超时** | 底栏红条提示"回复失败"，带重试按钮 |
| **网络断开** | 桌宠表情变 sad/委屈，恢复后自动切回正常 |
| **TTS 语音生成失败** | 角色做"无法说话"动作（捂嘴/无奈），降级为纯文字显示 |
| **API Key 未配置/失效** | 角色做出反馈动作 + 自动弹出 AI 设置界面 |

> 错误恢复后角色表情自动切回正常。API Key 问题需用户主动操作解决，所以要弹出设置。

---

### 6. 桌宠生命周期——窗口操作时的行为

> 已确定。

核心原则：**角色独立于窗口存在。窗口是角色的栖息地，不是容器。**

角色三种位置状态：`桌面自由态` ←→ `窗口坐边框` ←→ `隐藏（托盘）`

| 用户操作 | 角色行为 | 动画 |
|---------|---------|------|
| 双击桌宠 / 右键→聊天 | 跳到聊天窗口顶栏坐下 | 跳上边框 300ms ease-out |
| 关闭聊天窗口 (✕) | 从边框跳下 → 桌面自由态 | 跳下 250ms ease-out |
| 最小化聊天窗口 | 从边框跳下 → 桌面自由态 | 跳下 250ms ease-out |
| 从任务栏恢复窗口 | 从桌面跳回窗口边框坐下 | 跳上边框 300ms ease-out |
| 拖拽聊天窗口 | 坐在边框上随窗口移动 | 无额外动画 |
| 聊天窗口最大化 | 跳到桌面自由态，恢复时坐回 | 跳下/跳上 |
| 从最大化恢复 | 坐回标题栏 | 跳上 300ms |
| 关闭设置窗口 | 聊天开着→坐聊天窗；否则→桌面 | 跳下或瞬移 |
| 从窗口拖拽角色到桌面 | 桌面自由态 | 被抓+放下 |
| 从桌面拖拽角色到窗口 | 坐回边框 | 跳上 300ms |

**多显示器**：暂不专门适配。窗口和角色默认在主屏。

---

### 7. 右键对话气泡

> 已确定。

- **停留时长**：鼠标移出气泡区域后消失
- **连续右键**：堆叠模式——已有气泡向上飘动淡出，新气泡在下方出现
- **朝向**：根据角色在屏幕上的位置动态调整——靠左边缘→朝右，靠右边缘→朝左，中间→默认朝左
- **跟随**：气泡跟随角色移动
- **消失动画**：向上飘动 + 淡出

---

### 8. 系统托盘

> 已确定。

托盘图标显示当前选中角色的大头照（50% 圆形裁剪），右键菜单：

```
┌─────────────────┐
│  显示/隐藏桌宠    │
│  打开聊天窗口     │
│  ──────────────  │
│  切换角色  ▶     │  ← 展开角色列表
│  ──────────────  │
│  退出            │
└─────────────────┘
```

- **显示/隐藏桌宠**：适用场景——用户看视频/打游戏时，桌宠始终置顶碍事，点击隐藏，完事再显示
- **关闭窗口时**：托盘图标保留，桌宠退回桌面。双击托盘打开聊天窗口
- **退出**：完全退出程序，桌宠消失、窗口关闭
