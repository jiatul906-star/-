# UI 规格

> 状态：起草中 | 最后更新：2026-05-15

## 核心理念

角色和窗口**分离但关联**——关闭窗口角色不消失，退回桌面。角色始终在线，是一个"伴侣"而非软件装饰。

---

## 整体风格

- 浅色为主，窗口圆润，参考 QQ 面板布局
- 字体：微软雅黑（`"Microsoft YaHei", "Segoe UI", system-ui, sans-serif`）
- 面板风格参考 QQ（左侧竖排头像栏 + 右侧内容区）

---

## 三级菜单结构

### Level 1 — 桌宠模式（桌面流浪）

- 角色独立悬浮桌面，无窗口
- 角色自由走动/待机，可拖拽到任意位置
- **左键**：互动菜单（具体条目待定）
- **右键**：弹出对话气泡（漫画风，从角色嘴边引出，无历史记录，自动消失）
- **拖拽**：播放"被抓起来"的动作帧，放下切回站立/坐下

### Level 2 — 聊天模式

参考 QQ 面板：左侧竖排头像栏 + 右侧聊天区。

```
    ┌────────────────────────────┐
    │     角色骑在顶栏边框       │
    ├────┬───────────────────────┤
    │ ○  │  角色A                │  ← 顶栏：小头像 + 名字
    │ ○  ├───────────────────────┤
    │ ○  │                      │
    │ ○  │  聊天消息区           │
    │ ○  │  AI气泡 / 用户气泡     │
    │ ○  │                      │
    │ ○  │                      │
    │ +  ├───────────────────────┤
    │    │  输入框         [发送] │
    └────┴───────────────────────┘
       ↑
      左侧角色列表（竖排圆形头像）
      选中态高亮
```

- **左侧角色栏**：竖排圆形头像列表，可切换角色。是否可收起——待定。
- 窗口圆润，偏窄，适合常驻桌面
- 移动窗口 → 角色跟着走
- 拖拽角色离开窗口 → 回到 Level 1
- 把角色扔到窗口顶部 → 自动坐回去
- 流式逐字输出，末尾有呼吸光标

**显示密度**：用户可选择两种模式

| 模式 | 正文 | 行高 | 气泡间距 |
|------|------|------|---------|
| 舒适 | 15px | 1.6 | 12px |
| 紧凑 | 14px | 1.5 | 8px |

### Level 3 — 设置模式

- 独立设置窗口
- 角色可以骑在设置窗口边框上
- 左侧角色切换，右侧设置面板

```
┌──────────────────────────────────────┐
│  设置                          [✕]   │
├─────────────┬────────────────────────┤
│  角色列表    │  当前角色编辑           │
│             │  外观 / 性格 / 声音     │
│  ○ 角色A    │                        │
│  ○ 角色B    │  AI 设置               │
│  ○ 角色C    │  API地址 / Key / 模型  │
│  + 新建     │                        │
│             │  界面布局设置           │
│  ────────  │                        │
│  外观/关于  │                        │
└─────────────┴────────────────────────┘
```

## 窗口与角色关联规则

| 状态 | 窗口 | 角色位置 |
|------|------|---------|
| Level 1 | 无窗口 | 桌面任意位置，可拖拽 |
| Level 2 | 聊天窗口 | 骑在窗口顶栏边框 |
| Level 3 | 设置窗口 | 骑在设置窗口顶栏/角落 |

---

## 对话气泡设计（Level 1 右键）

- 漫画风格，从角色嘴边引出
- 无历史记录功能
- 短暂显示后自动消失
- 不是矩形输入框，是纯展示气泡

---

## 设计原则

1. **递进式复杂度**：Level 1 最简，Level 3 功能最全
2. **角色不挡内容**：角色坐在边框上，不占窗口内部空间
3. **始终陪伴**：关闭窗口不等于关闭角色
4. **窗口小巧**：不做大而全的面板，适合长期驻留桌面
