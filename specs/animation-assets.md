# 桌宠动画素材清单

> 状态：待用户确认/制作 | 最后更新：2026-05-16

## 素材规格

| 属性 | 要求 |
|------|------|
| 格式 | PNG 序列帧 或 APNG/GIF（推荐 PNG 序列帧，方便替换） |
| 尺寸 | 建议统一画布（如 256×256 或 512×512），角色居中偏下 |
| 帧率 | 12fps（每秒 12 帧），复杂动作可到 15fps |
| 背景 | 必须透明 |
| 命名 | `{角色名}_{动画名}_{帧号}.png`，如 `xiaotao_idle_001.png` |

> 当前桌宠素材已有，这里列的是"每个角色需要覆盖的动画"。如果已有素材不全，按优先级补。

---

## 动画清单

### P0 — 必须有（首版能跑）

| 动画 | 帧数 | 时长 | 说明 |
|------|------|------|------|
| **idle** 待机 | 8-12 帧 | ~1s 循环 | 角色站着/坐着，轻微呼吸起伏。最常用的基础态 |
| **walk** 走动 | 6-8 帧 | ~0.5s 循环 | 桌面流浪时的走动。可只做左右两个方向，或做一套然后用 flip |
| **blink** 眨眼 | 3-4 帧 | ~0.3s 单次 | 叠加在 idle 上，随机触发（每隔 2-5 秒来一次） |
| **talk** 说话 | 4-6 帧 | ~0.4s 循环 | 嘴巴张合，配合 TTS/对话气泡。叠加在 idle 上 |
| **grabbed** 被抓 | 1 帧 | 静态 | 被拖拽时的状态，通常是被拎起来的样子 |
| **jump_on** 跳上 | 6-8 帧 | 300ms 一次 | 从桌面跳上窗口边框 |
| **jump_off** 跳下 | 6-8 帧 | 250ms 一次 | 从窗口边框跳下桌面 |

### P1 — 交互反馈

| 动画 | 帧数 | 时长 | 说明 |
|------|------|------|------|
| **react_happy** 开心 | 4-6 帧 | ~0.4s 单次 | 被戳后随机触发之一：笑/跳一下 |
| **react_shy** 害羞 | 4-6 帧 | ~0.4s 单次 | 被戳后随机触发之一：脸红/扭头 |
| **react_angry** 生气 | 4-6 帧 | ~0.4s 单次 | 被戳后随机触发之一：跺脚/嘟嘴 |

### P2 — 错误反馈

| 动画 | 帧数 | 时长 | 说明 |
|------|------|------|------|
| **think** 思考 | 4-6 帧 | ~0.4s 循环 | AI 请求中：歪头/眨眼/托腮 |
| **sad** 委屈 | 4-6 帧 | ~0.4s 循环 | 网络断开：低落/垂头 |
| **silent** 无法说话 | 4-6 帧 | ~0.4s 单次 | TTS 失败：捂嘴/无奈摊手 |

## 动画层级说明

有些动画是"叠加层"——在基础动画上额外播放：

```
idle（持续循环）
  ├── + blink（随机插入，播完回到 idle）
  ├── + talk（说话时叠加，停止说话回到 idle）
  └── + think（AI 请求时切换，完成后回到 idle）
```

实现建议：角色用两个图层
- **身体层**：idle / walk / grabbed / sad 等 → 互斥切换
- **表情层**：blink / talk → 叠加在身体层上

## 总计

| 优先级 | 数量 | 总帧数（估算） |
|--------|------|--------------|
| P0 必须 | 7 个动画 | ~50 帧 |
| P1 交互 | 3 个动画 | ~15 帧 |
| P2 错误 | 3 个动画 | ~15 帧 |
| **合计** | **13 个动画** | **~80 帧/角色** |

## 捷径方案

如果帧动画工作量大，可简化：

| 简化项 | 做法 |
|--------|------|
| walk 不画 | 角色只在原地 idle，拖拽结束瞬移到新位置（很多桌宠软件这么做） |
| 左右翻转 | 只画一套向右的，向左用 CSS `scaleX(-1)` 或图片水平翻转 |
| 错误表情 | sad/silent/think 简化成 1-2 帧静态表情，不做动画 |
| react 合并 | 只做一种 react，随机换台词而非换动画 |
