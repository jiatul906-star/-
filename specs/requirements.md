## 二、一级 — 纯角色（桌面流浪）

**设计稿**：`一级.png`（327×490）

角色独立悬浮于桌面，无窗口边框。

- 角色会随机在桌面行走（待机呼吸动画 + 随机眨眼）
- 戳角色身体 → 随机反应动画 + 台词气泡
- 拖拽角色到任意位置 → 播放"被抓"帧，放下切回待机
- 右键弹出环形菜单（含聊天 / 摸头 / 扩展条目）+ 迷你聊天气泡
- 左键拖拽桌宠移动
- 角色始终置顶，独立于聊天窗口存在

> 以上内容来自 `docs/ui-spec.md` Level 1 已确定项。

## 三、二级 — 角色正下方有聊天框，动作按钮环绕角色

**设计稿**：`二级.png`（604×570）

右键点击角色后弹出。设计稿 OCR 识别到的元素：

- **展开聊天** — 按钮文字，点击后进入三级大聊天窗口
- **设置** — 按钮文字，点击后进入四级设置界面
- **摸头** — 交互按钮（设计稿中有对应按钮）
- 动作按钮以角色为中心环形排列，有弹簧动画弹入/弹出效果

迷你聊天气泡：角色嘴边弹出，支持直接输入文字与 AI 对话。流式逐字输出。鼠标移出气泡区域后消失。连续右键堆叠显示（旧上飘、新下出）。

> 以上内容来自 `二级.png` OCR 识别结果 + `docs/ui-spec.md` Level 1 右键交互已确定项。

## 四、三级 — 大聊天界面

**设计稿**：`三级.png`（1509×1056）

### 4.1 设计稿 OCR 识别到的内容

**标题栏区域**（左上）：
- 角色头像 + 角色名
- 设置按钮（齿轮图标，位于名字右侧）
- AI 聊天模型选择器（截图显示 "DeepSeek" 下拉框，位于设置按钮右侧）
- 窗口控制按钮（最小化 / 最大化 / 关闭）

**左侧角色栏**：
- 竖排圆形头像列表 — 当前角色高亮

**聊天消息区**（设计稿中的消息记录）：
- 用户消息（右对齐，主题色气泡）："今天星期几"
- AI 回复（左对齐，浅色气泡）："(垂着头想了想) 嗯…让我看看窗外的太阳。应该是星期三吧？我闻到隔壁飘来的午饭香味了。"
- 用户消息："你在干嘛"
- AI 回复："(正在摆弄一片落叶) 我在数蚂蚁搬家呢。你看，它们排着队，像在跳一支小小的舞蹈。真有趣。"
- 用户消息："你是喉娘，每句话后面加'喉'"
- AI 回复："啊，被你发现了喉~(眨眨眼睛) 我确实有点猫猪属性喉。不过今天阳光太好了，让我想打个盾儿喉~。"
- 每条消息带时间戳（格式 `HH:MM`，如 21:28、21:30、21:38）

**底部输入区**：
- 输入框提示文字"输入消息..."
- 发送按钮

### 4.2 对应 UI 规格（docs/ui-spec.md Level 2 已确定项）

**布局**：参考 QQ 面板 — 左侧竖排头像栏 + 右侧聊天区。

```
┌────────────────────────────────────────────┐
│     角色骑在顶栏边框                       │
├────┬───────────────────────────────────────┤
│ ○  │  角色名                    [─ □ ✕]   │
│ ○  ├───────────────────────────────────────┤
│ ○  │  聊天消息区                           │
│ ○  │  AI气泡 / 用户气泡                    │
│ ○  │                                       │
│ +  ├───────────────────────────────────────┤
│    │  输入框                    [发送]      │
└────┴───────────────────────────────────────┘
```

**窗口尺寸**（对齐 `src/main/windows/chat.ts` 实际代码）：

| 属性 | 值 |
|------|-----|
| 默认宽 | 960px |
| 默认高 | 680px |
| 最小宽 | 680px |
| 最小高 | 480px |
| 圆角 | 10px |
| 标题栏高度 | 40px |
| 左侧角色栏宽度 | 52px（多角色）/ 22px（单角色） |

**消息区**（docs/design-system.md）：

| 参数 | 值 |
|------|------|
| AI 气泡背景 | 跟随主题 `--color-bubble-ai` |
| 用户气泡背景 | 跟随主题 `--color-bubble-user` |
| 气泡圆角 | 18px |
| 气泡最大宽度 | 75% |
| 气泡内 padding | 10px 14px |
| 同发送者连续气泡间距 | 2px |
| 不同发送者气泡间距 | 8px |
| 正文大小 | 15px（舒适）/ 14px（紧凑） |

**标题栏元素顺序**（设计稿 OCR 识别）：
`[角色头像] [角色名] [⚙设置按钮] [AI模型选择器▼] ... [窗口控制]`

**角色切换**：点击左侧栏头像 → 聊天历史切换为该角色的记录，桌宠形象同步更新。

**流式输出**：AI 回复逐字显示，末尾呼吸光标。

## 五、四级 — 设置界面

**设计稿**：`四级-1.png`（1243×898）

### 5.1 设计稿 OCR 识别到的元素

**弹窗标题栏**：文字"设置 ✕"

**左侧导航**：
- **角色编辑** — 标题下有描述文字"自定义角色的外观、性格和声音"
  - 角色列表项：`小桃`（当前选中）
  - `+ 新建角色` 按钮
- **外观** — 导航项
- **API** — 导航项
- **关于** — 导航项

**右侧内容区**（选中角色"小桃"时）：

三标签切换：`[外表] [灵魂] [声音]`

**外表标签**（OCR 识别到的字段）：
- **角色名称** — 文本输入框
- **角色头像/立绘** — 上传区域，提示文字"支持 JPG/PNG/GIF, 建议 1:1 比例"
- **桌宠动作** — 管理区域
- **使用默认形象** — 开关选项

**头脑标签**（2026-07-01 补充 OCR，来源 `ba524914...png`）：
- **脑中提示词** — 文本输入框，自由文本描述角色性格
- **说话风格** — 文本输入框，描述角色的说话方式（如：喜欢用颜文字、每句话后面加"喵"）
- **角色专属 API** — 下拉选择框，可为该角色选择专用的 API 配置；选择"跟随全局"则使用顶部全局 API 设置
- 下方实时显示 System Prompt 预览

**智能体记忆**（2026-07-01 补充 OCR，来源 `05e7045...png`）：
- **智能体记忆** — 可添加/删除记忆条目
- 记忆条目格式：`添加新记忆。如:用户喜欢吃火锅`
- **System Prompt 预览** — 实时拼接 Prompt，展示完整 System Prompt 文本
- **导入/导出** — 支持记忆 JSON 导入/导出

### 5.2 对应 UI 规格（docs/ui-spec.md Level 3 已确定项）

设置是独立弹窗，浮在聊天窗口上方（CSS overlay）。

```
         ┌──── 设置弹窗 ──────────┐
         │  设置           [✕]    │
         ├────────┬───────────────┤
         │ 角色编辑│  当前角色编辑  │
         │ ○ 小桃  │               │
         │ ○ 小黑  │ [外表][灵魂][声音]│
         │ + 新建  │   [内容区]     │
         │ ────── │               │
         │  AI设置 │               │
         │  外观   │               │
         │  关于   │               │
         └────────┴───────────────┘
```

**角色编辑 — 三个标签**（docs/ui-spec.md）：

① **外表**：
- 立绘上传（对话时展示的角色形象）
- 头像上传（侧栏/托盘图标用，圆形裁剪）
- 桌宠形象上传（桌面流浪时的角色图）
- 每张图支持裁剪和实时预览

② **性格**：
- 模板模式：预设标签点击添加/删除（温柔/傲娇/话唠/安静/幽默/毒舌/元气/冷淡等）
- 自由文本模式：文本区自然语言描述
- 两种模式可叠加

③ **声音**：
- 语速滑块（0.5 - 2.0）
- 音调滑块（0.5 - 2.0）
- 音量滑块（0.0 - 1.0，默认 0.8）
- 试听按钮

**AI 设置**（左侧导航）：
- API 地址输入框
- API Key 密码输入框
- "测试连接"按钮，点击后有成功/失败反馈

**界面外观**（左侧导航）：
- 主题色选择：暖桃 / 薄荷 / 薰衣草 / 奶咖 / 樱花
- 明暗模式：浅色 / 暗色
- 显示密度：舒适（15px）/ 紧凑（14px）

> 以上全部内容来自 `四级-1.png` OCR 识别结果 + `docs/ui-spec.md` + `docs/design-system.md` + 2026-07-01 补充 OCR（`ba52491...png`、`51e9497...png`、`7131ede...png`、`05e7045...png`、`850faf5...png`）。

## 七、2026-07-01 新增需求（来源：`5.md` + 6 张截图 OCR）

### 7.1 声音标签标为待开发

整个声音标签（语速/音调/音量滑块 + 试听按钮）标注"待开发"，不在当前阶段实现。

### 7.2 右键菜单动作按钮可自定义

> 来源：`51e9497...png` OCR — 设置 > 动作按钮配置

- 按钮数量可自定义（可新增/删除按钮）
- **聊天按钮不可删除**（"展开聊天"属于系统动作，受保护）
- 按钮功能在设置界面编辑
- 设置界面左侧导航新增"动作"项
- 按钮功能列表：可编辑每个按钮的显示名称、emoji、绑定视频路径
- OCR 识别到的现有按钮：摸摸头（视频 1-1.mp4）、喂食（视频 1-2.mp4）、展开聊天（系统动作）

### 7.3 右键聊天气泡渐隐规则

- 点击聊天气泡时，聊天框下移两条信息的宽度
- 发送和回复的信息超过两条 → 旧消息变淡并消失
- 最新 2 条始终保持全亮
- 气泡消失动画：向上飘动 + 淡出

### 7.4 智能体记忆导入/导出

- 智能体记忆（agent memory）添加导出功能（JSON 文件）
- 添加导入功能（从 JSON 文件恢复记忆）
- 导出格式：`agent-memory-{角色名}-{日期}.json`
- 导入时校验 JSON 结构，不合法则提示错误
- 对应文件：`characters/{charId}/memory.json`（待角色分目录迁移后生效）

### 7.5 API 配置界面补充

> 来源：`850faf5...png` OCR + `7131ede...png` OCR + 聊天窗口 API 选择器 OCR

- 设置 > API：多配置列表 + 新建配置/保存/删除/设为当前/测试连接
- 新建配置字段：名称、Base URL（OpenAI 兼容接口地址）、Key、模型
- 新建配置 → 填写 → 保存 → 在聊天窗口标题栏 API 选择器下拉中可见
- "设为当前"切换全局激活配置
- 聊天窗口标题栏 API 选择器：下拉列出所有已配置 API，选中项加"当前"标记

### 7.6 设置界面完整布局（OCR 确认）

> 来源：多张设置截图综合

左侧导航项（OCR 确认）：角色 / 外观 / 动作 / API / 关于
