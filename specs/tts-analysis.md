# TTS 方案分析

> 状态：供用户+程序员决策 | 最后更新：2026-05-17

## 约束条件

- Electron 桌面应用
- 中文语音为主
- 4 个角色需要不同音色
- 偏好流式播放（边生成边播）
- 成本敏感（独立项目）

---

## 候选方案

| 方案 | 质量 | 离线 | 成本 | 中文音色数 | 流式 |
|------|------|------|------|-----------|------|
| **A. Edge-TTS** | ★★★★ 自然 | ✗ 需联网 | 免费 | 20+ | ✓ |
| **B. 浏览器 SpeechSynthesis** | ★★ 机械 | ✓ | 免费 | 系统自带 2-4 个 | ✗ |
| **C. 本地 VITS** | ★★★★★ | ✓ | 免费 | 可定制 | ✓ |

| **E. OpenAI TTS** | ★★★★★ | ✗ | $15/百万字 | 6（含中文） | ✓ |

## 逐方案分析

### A. Edge-TTS（推荐首选）

微软免费的文本转语音服务，微软没有公开 API 文档，但社区已封装了 Node.js 库。

**优点：**
- 免费，无配额限制
- 中文音色 20+，足够给 4 个角色分配不同声音
- 音质自然，接近真人
- 有 `edge-tts` npm 包（`npm i edge-tts`），Electron 可直接用
- 支持流式（SSML → 分句请求 → 逐段播放）

**缺点：**
- 必须联网，无网络时不可用
- 非官方 API，微软可能某天封堵（但已稳定运行两年+）
- 单次文本过长时需分段请求

**角色音色匹配示例：**

| 角色 | 音色 ID | 风格 |
|------|---------|------|
| 元气少女 | `zh-CN-XiaoxiaoNeural` | 活泼明亮 |
| 傲娇 | `zh-CN-XiaoyiNeural` | 年轻自信 |
| 温柔 | `zh-CN-XiaochenNeural` | 温柔清澈 |
| 冷淡 | `zh-CN-YunxiNeural` | 低沉成熟 |

**实现要点：**
```
用户消息 → AI 生成文本
              ↓
         按句拆分（以。！？为界）
              ↓
         逐句调 edge-tts → 返回 mp3 buffer
              ↓
         HTML5 Audio 逐段播放（上一段将结束时预加载下一段）
              ↓
         角色播 talk 动画，播完切 idle
```

### B. 浏览器 SpeechSynthesis

Chromium 内置的 Web Speech API，零依赖。

**优点：**
- 零依赖，`window.speechSynthesis.speak()`
- 离线可用（Windows 自带 2 个中文声音）

**缺点：**
- 音色机械，"机器人味"明显——和"伴侣"定位冲突
- 中文音色极少，4 个角色音色区分度不够
- 不支持流式，整段文本一次性播
- 不同操作系统声音不同，不可控

**结论：** 不建议。音质和产品定位不符。

### C. 本地 VITS

开源中文语音合成模型，可微调出不同音色。

**优点：**
- 完全离线
- 音质极好
- 可训练专属音色

**缺点：**
- 模型文件大（2-5GB）
- 首次配置复杂（Python 环境、模型下载）
- 推理速度取决于 GPU，纯 CPU 较慢
- 和 Electron 集成需额外进程通信（Python 子进程或 HTTP 服务）
- 4 个角色需 4 个不同模型或 1 个多说话人模型

**结论：** 音质天花板，但工程复杂度太高，不适合首发。可作为后期升级方向。

### D/E. Azure / OpenAI 付费 API

**优点：** 音质顶级，服务稳定

**缺点：** 持续成本。按 4 个角色 × 日常对话量估算，每月可能 ¥50-200。不适合独立小项目。

---

## 推荐路线

```
首发（P5）→ 方案 A：Edge-TTS（免费，联网，音质好）

后期可选升级：
  ├── 用户要求离线 → 方案 C：本地 VITS
  └── 愿意付费 → 方案 D：Azure 正式 API
```

## 角色声音配置结构

无论选哪个方案，每个角色的声音设置统一存为：

```json
{
  "voiceId": "zh-CN-XiaoxiaoNeural",
  "speed": 1.2,
  "pitch": 1.0,
  "volume": 1.0
}
```

| 字段 | 说明 | 范围 |
|------|------|------|
| `voiceId` | TTS 引擎的音色标识符 | 取决于方案 |
| `speed` | 语速 | 0.5 ~ 2.0（1.0 = 正常） |
| `pitch` | 音调 | 0.5 ~ 2.0（1.0 = 正常） |
| `volume` | 音量 | 0.0 ~ 1.0 |
